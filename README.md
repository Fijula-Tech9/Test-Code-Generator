# Test Code Generator

This extension helps you generate test code with a simple UI.

## Features
- Select between Feature File and Page Class generation
- Provide additional information for code generation
- Inspect and generate code with a single click

## UI Overview
The main interface includes:
- Tabs for **Code Generator** and **Configure**
- Checkbox options for **Feature File** and **Page Class**
- A large text area for input
- An additional information field
- Two main buttons: **Inspect** and **Generate**


## Getting Started
1. Clone the repository.
2. Install dependencies if required.
3. Load the extension in your browser or development environment.

## Usage

1. Open the extension in your browser or development environment.
2. Select the desired options:
	- **Feature File**: Generate feature files for your tests.
	- **Page Class**: Generate page class code for your automation framework.
3. Enter your test scenario or requirements in the main text area.
4. Optionally, provide additional information in the field below.
5. Click **Inspect** to review your input or **Generate** to create the code.

### Example Workflow

1. Check the **Page Class** option.
2. Enter your page object details in the text area.
3. Click **Generate** to create the page class code.
4. Copy the generated code to your project.
